# Погода — Data Binding

Минимальное приложение на основе [CurrentWeatherDataBinding](https://github.com/ipetrushin/CurrentWeatherDataBinding).
Один экран: список городов, температура, описание погоды и кнопка обновления.
Выбор города сразу запускает загрузку. Сетевые ошибки показываются на экране.

В `activity_main.xml` тег `<data>` описывает данные погоды, состояние загрузки,
сообщение и обработчик кнопки. Интерфейс обновляется через выражения `@{...}`.
Запрос к OpenWeatherMap выполняется в корутине на `Dispatchers.IO`;
при закрытии Activity корутины отменяются.

Для реальной погоды добавьте `OPENWEATHER_API_KEY=ваш_ключ` в `local.properties`
и пересоберите приложение. Существующую строку `sdk.dir` оставьте.
Без ключа приложение показывает сообщение о его отсутствии.
Ключ не хранится в Git, но после сборки входит в APK.

Gradle-зависимости относятся к приложению, а не устанавливаются как системные программы.
При сборке Android Studio обычно скачивает недостающие зависимости в свой кэш.
Чтобы запретить скачивания, включите Gradle Offline Mode. Если нужных файлов ещё нет,
офлайн-сборка завершится ошибкой; в таком случае сборку нужно выполнять в виртуальной машине.
